    Never delete and automatic cleanup

    Never delete applies to manual, bulk, and automatic cleanup in this plugin. Protecting a show includes its current and future episodes. All watch states are shown by default, including unwatched titles. Use each title's protection button below, or select rows and choose Never delete selected. You do not need to allow unwatched deletion to protect unwatched media. Remove a show's protection here before changing an inherited episode protection.

    Cleanup rules

    Rules use the chosen user's saved completion flag. A show is complete only when all currently available episodes are marked watched. Resume mode includes completed items with saved positions; unfinished viewing for any user stays protected. All native permissions, playback, path, and configured service checks remain in effect.

    Emby checks schedules every minute. Event triggers settle for 30 seconds and are limited to one evaluation per rule per 15 minutes. Item events evaluate those items, or their completed show. Review prompts appear here while this page is open. Evaluate now always prepares a review, even for an automatic rule.
